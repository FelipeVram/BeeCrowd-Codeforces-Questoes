# Programação Competitiva

Repositório com minhas soluções para problemas de programação competitiva, resolvidos nas plataformas:

- 🐝 [BeeCrowd](https://www.beecrowd.com.br/)
- 🔵 [CodeForces](https://codeforces.com/)

🎯 Objetivos

Este repositório documenta minha jornada de estudo e prática em programação competitiva. Os principais objetivos são:

- Fortalecer a lógica de programação e a capacidade de resolver problemas sob restrições de tempo e memória;
- Aprofundar o domínio de estruturas de dados (vetores, listas, pilhas, filas, árvores, grafos) e algoritmos clássicos (busca, ordenação, programação dinâmica, guloso, etc.);
- Praticar e consolidar conceitos de linguagem, como manipulação de ponteiros e alocação de memória em C;
- Ganhar familiaridade com a leitura e interpretação de enunciados em diferentes formatos e níveis de dificuldade;
- Me preparar para maratonas de programação (como a Maratona SBC) e processos seletivos técnicos;
- Acompanhar minha evolução ao longo do tempo, revisando soluções antigas e comparando com abordagens mais eficientes.

🛠️ Linguagens

Principalmente C e C++.
